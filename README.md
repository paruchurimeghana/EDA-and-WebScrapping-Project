# 🚗 Cars24 Used Cars Data Analysis
# 📌 Project Overview
This project analyzes used-car listings collected from Cars24 using web scraping, Python, Pandas, Exploratory Data Analysis and Power BI.

# 🎯 Business Objectives
Analyze used-car listings city-wise
Identify popular brands and models
Compare pricing across cities and brands
Analyze fuel type and transmission preferences
Study the relationship between price, KM driven and vehicle age
Generate business insights for inventory and pricing decisions

# 📊 Dataset
2,004 used-car listings
30 cities
14 attributes

# 📈 Key Findings
2,004 listings were analyzed across 30 cities.
Chandigarh recorded the highest listing volume.
Maruti had the strongest brand representation.
Petrol vehicles dominated the collected listings.
Manual transmission represented the majority of listings.
Average listed price was approximately ₹5.56 lakh.
Median listed price was approximately ₹4.83 lakh.

# 💡 Business Recommendations
Optimize inventory by city.
Focus on high-demand brands and models.
Use data-driven pricing strategies.
Segment inventory based on customer preferences.
Monitor market trends regularly using dashboards.
